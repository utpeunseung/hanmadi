資料

換手機或換瀏覽器時：在舊裝置「匯出備份」，把 JSON 檔傳到新裝置後「匯入備份」。同一個單字會合併，不會重複。Anki 檔是用 Tab 分隔的文字檔，在 Anki 選「檔案 → 匯入」即可，正面是韓文，背面是中文意思和解說。

加到手機桌面

Android：用 Chrome 開啟這個網頁（建議放在自己的網址，例如 GitHub Pages），點右上角 ⋮ →「加到主畫面」。之後從桌面圖示開啟，就像一般 app。

發音使用手機內建的語音。如果按 ▶ 沒有聲音：Android 到「設定 → 系統 → 語言 → 文字轉語音輸出 → Google 語音服務 → 安裝語音資料」，下載「韓文」。
